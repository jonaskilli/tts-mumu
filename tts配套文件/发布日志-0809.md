## TTS-Server v1.26 更新日志

---

### 🔥 核心大改动

**1. 发音人名字实时同步（切分组自动跟随）**
- 角色管理存储底层 voice 标识，切换前台分组后发音人显示名自动跟随当前分组绑定，不再显示上一次分组的名字
- 列表和筛选弹窗都显示当前分组的中文显示名，配置项失效时标 ⚠
- **连带影响：彻底移除性格（personality）板块**。为实现名字同步，标签格式从源头改为纯 tag（不再拼 personality 后缀），app 端不再调用 JS 拼性格、改用配置项 displayName；匹配链路从五级降为四级；启动时自动迁移旧配置并清理 tagData 中的 personality 字段，配置项编辑页隐藏性格输入框

**2. 响度均衡（自动音量平衡）**
- 自动学习每个发音人（按底层 voice 区分）的音量特征，把所有发音人音量拉平，无需手动逐个调
- 播放时后台分析音频实际响度，偏轻的放大、偏响的降低，最多学习 32 段/发音人，越播越准
- 在手动音量基础上额外补偿，新发音人首段增益 1.0 不调、播几段后自动修正
- 带语音活动检测只分析人声、软限幅防爆音
- **设置页新增响度均衡总开关**（默认开启）：位于 设置 → 系统 TTS 顶部，可随时关闭/开启，切换即时生效无需重启
- **新增「重置响度学习数据」入口**：设置页显示已学习发音人数量，点击弹确认对话框防误触

**3. 兜底发音人体系**
- 朗读规则层：角色无法识别/AI 分析失败/无可用发音人时，按性别自动分配兜底 tag（男→duihuaA、女→duihuaB、未知→duihua）
- app 端备用层：播放重试失败时按"同标签备用 → 性别兜底"链路切换，兜底发音人自身不再挂备用
- 报错只记录日志不改变播放行为（静音/重启由用户设置决定）
- 删除了原全局备用发音人设置（性别兜底已覆盖全场景，不再冗余）

**4. 插件切换引用配置**
- 插件管理菜单新增「切换引用配置」，可把所有引用某插件 id 的配置项批量改为目标插件 id
- 换插件后无需逐个改配置项，一键迁移引用

**5. 导入导出增强**
- **导出多级粒度**：可按单配置项、单分组（含其下子分组）、多分组整体三种粒度导出，文件名按粒度自动生成（如"分组名-3项"、"2个分组-8项"），大 JSON 序列化移到后台线程避免卡顿
- **导入自动识别**：各类配置导入支持自动识别 JSON 类型直接导入，无需再手动选择类型和点导入按钮
- 统一导出格式为 GroupWithSystemTts，增大导入缓冲区解决大 JSON 闪退
- **四种导入失败时显示完整报错**：配置列表 / 替换规则 / 朗读规则 / 插件导入解析失败时，从仅显示两行 Toast（被截断、无法复制）改为弹出可滚动、可选中复制的错误对话框，短报错一眼看全、长报错一键复制全文去排查
- **替换规则单项导出**：替换规则列表单项菜单新增「导出」项，可导出单条规则为 JSON 文件，文件名自动生成为 `ttsrv-replace-<规则名>.json`

---

### 🗂️ 分组菜单操作（增强）
- **多选转为子分组**：多选若干一级分组，批量降级为某分组的子分组；支持新建一级分组作为目标
- **多选转为一级分组**：含子分组的一级分组菜单，可多选子分组各自转为独立一级分组
- **移动子分组**：多选子分组（支持全选）移动到其他一级分组
- 配置列表多选底部操作栏：全选 + 删除 + 转为子分组
- 多选合并分组、移动操作改为批量 DB 写入 + 弹窗即时反馈

---

### 🏷️ 标签
- 主界面标签快速切换：点击标签弹两层选择器（分类 + 序号），默认定位当前分类
- 标签顺序按自定义排序，不再字典序
- 本地音效标签统一为 1-100 循环

---

### 🎭 朗读规则 & 角色管理

- **发音人失效后保留显示 + 朗读时重新分配**：删除发音人配置项后，角色列表不再立即清空 voice，而是保留旧 tag 并标 ⚠（过渡态）；朗读到该角色时自动重新分配一个有效的同类发音人并写回，避免删除配置项导致角色"裸奔"
- **标签扩容兜底**：`GENSHIN_CHARACTERS` 仅含初始序号（如女青年 01~100），配置项若有超出范围的 tag（如女青年 517）会匹配不到。现已扫描 `tagsData` 中「已知前缀+序号」格式的 key，视为扩容标签加入 `availableVoices`，避免被误判为失效
- **角色管理界面布局简化**：移除第二行 emoji 点亮栏，发音人名改为 `weight=1` 撑满剩余空间，⋮菜单和试听按钮推到行末，名字短也有足够点击区域
- **兜底修复**：`generateVoiceTag` 异常返回 null 时，用 `voice + ⚠` 保持右侧显示不塌陷
- emoji 标记支持多选（❤️/🚶/😈 可同时点亮）
- 角色栏打开和筛选弹窗秒开（批量查询优化）
- 单击/长按只在角色名区域生效，右侧按钮不误触

---

### 🐛 稳定性修复

- 修复切换前台分组后配置项标感叹号且不能试听
- 修复后台线程刷新界面导致的崩溃
- **修复替换规则导入失败的 bug**：`toJsonListString()` 检查的是原始字符串（含首尾空格）而非 trim 后的，导致给已合法的 `[...]` 错误补括号变成 `[[...]]`，解析报 `Expected EOF after parsing, but had ] instead`
- **修复「指定配置朗读」时 BEFORE 替换不生效的 bug**：`TextProcessor` 在 `presetConfig` 路径下丢弃了 BEFORE 阶段的替换结果，导致通过指定配置朗读时替换规则（如「过滤段评」）失效
