# 更新说明 2026-08-22

## 播放

- 新增「段间停顿」设置：每段语音后插入固定时长的停顿，0~1000 毫秒可调，不受语速影响，改完立即生效（位置：系统 TTS 设置页）。按句朗读建议 400 毫秒左右

## 音频参数

- 修复：备用发音人、试听、指定语音朗读，现在会跟随你在全局/分组/插件级设置的音量、语速、音调了（之前这些地方只认配置里自己改的参数，改全局音量对它们无效）
- 日志和试听弹窗会显示实际生效的倍率，如「语速2.00x 音量0.80x」，参数到底调没调到一目了然
- 试听现在按朗读时的实际语速、音量、音调播放——试听到的就是听书时听到的效果

## 日志

- 获取失败显示中文原因（网络超时 / 被限流 / 认证失败 / 网络不通等），不再是一串英文报错
- 「耗时」统计对豆包、千问类插件也准确了（之前会显示 0 几毫秒，没有参考价值）
- 搜索改成了定位模式：自动跳到最近一条匹配并高亮，可用上一处/下一处逐个查看，也可打开「只看匹配」只显示命中的日志
- 日志层次更清楚：每条日志之间画一条浅色分隔线，所有条目平级无缩进；「请求音频」前缀和朗读正文都是绿色（前缀普通、正文加粗），「获取成功」与声音配置、语速音量等次级信息用石板灰弱化（「获取成功」的内容同样加粗），不再一整片绿看不清；备用配置只在实际切到时提示，不再每次都刷屏
- 日志文字行距恢复正常，不再挤在一起

## 其他

- 插件管理、替换规则支持多选后批量导出
- 修复角色管理栏打开时的黑影闪动
- 标签样式微调：更圆润、字重更协调
