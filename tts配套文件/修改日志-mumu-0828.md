## 一、JRead 兼容

- **JRead 插件格式全兼容**：支持 JRead 插件双格式导入导出，内置运行时垫层，修复语速刻度与 http 超时参数（dfb6004）
- **JRead 声音引擎配置列表导入**：支持 `jread_voice_config_bundle` 格式（c3b5fd0）
- **JRead 通用标签自动映射**：旁白式/斜杠式/主角式标签自动映射为 mumu 标签，补零规范化（598ea6f、732ecd1）
- **JRead 分组名转换**：长名式/群杂式/斜杠式映射短名，其余原样保留；后续收敛为仅年龄段长名与特殊转短名（74b9b29、b2043be）
- **JRead 三级分组照搬**：一级组名作 mumu 分组（同名复用），二三级留在 categoryPath（c35a71d）
- **修复 V2 插件探测 ttsrv 报「JavaScript 值无效」**：引擎 getter 规范化 + 垫层 JS 门面遮蔽（81e2b05）
- **修复 Rhino defineProperty 类型不匹配**：defineGetter 改用 Supplier（b23a49f）
- **子分组头操作聚合整棵子树**：勾选/删除/导出/整理标签均覆盖下级层级（418be7b）
- **修复 JRead 一级组名分桶导入丢失**（f45e965）
- **导入修复【新增】**：`data` 支持对象写法；子分组斜杠分段＋去重；主角标签空格归一；性格/群杂标签原样保留（3c4fe43）
- **特殊标签定版【新增】**：分组名斜杠式整体映射（女/女童、男/特殊）；子分组内嵌斜杠先整体映射再拆段（f01d1b7）；最终按实际标签库收紧——性格/尾缀分组整条原样保留不再映射，特殊标签补零、仅男主不补零（57ac0b8）
- **多层子分组层级区分【新增】**：子分组头按层级缩进且背景递减，深层配置项同步缩进对齐（8de6b45）

## 二、合并分组（新功能）

一级分组菜单新增「**合并到其他分组**」：

- 源分组**全部配置项**迁入目标分组，迁完自动删除源分组
- 分类路径按**关键词归一化**归堆：纳米/女青年 → 剪映/女青年（支持男女童少青中老、男主女主、特殊男女共 14 个关键词）
- 目标没有对应分类的项保留原路径，作为新子分类，不丢项
- 「**插入到开头**」开关：想优先用新插件声音时勾选，默认追加末尾
- 迁移后仅对**受影响分类**重新编号，无关分类不动；编号规则与朗读规则一致（女青年01 补零、男主1 不补零）
- 子分组定义随合并同步迁移：改名/移动/转出候选并入 JSON 键一起搬走（f09ea6c）
- **菜单形态回调【新增】**：一级分组菜单恢复 DropdownMenu 弹窗，撤销 ModalBottomSheet 实验；功能更名「**合并同类配置项到其他分组**」，文案明确空分组自动删除（573f84d）
- **弹窗副标题迭代【新增】**：先分行逐条列清合并方式/配置项去向/原一级分组与子分组处理（c2481f6），再按标签类型表述两种去向（63e8f3a），最终精简为一句：同关键词归并、其余转新子分组（f8e2730）

## 三、分组界面优化

- **一级分组序号徽章**：名字前显示主题色小序号方块，按列表位置自动编号，拖拽排序后自动重编，替代手动 emoji 序号；后续降饱和改用 surfaceVariant，纯信息元素不再抢交互元素注意力（99b5a6c）
- **修改子分组前缀**：一级分组菜单新增，批量添加/替换/去除子分组名前缀（查找留空=添加，替换留空=去掉），实时预览，音频参数随键名同步迁移；后续支持自动识别公共前缀并简化为单输入框（90e8cde）
- **空子分组可见化**：仅存于参数 JSON 的空子分组也渲染组头，可勾选/改名/删除/移出；新建或转子分组后立即可见，空一级组转子分组有目标提示且转换后删原组（ce66789、f09ea6c、37b35f9、86b11d9、1e8de1a）
- **空一级分组修复**：放宽确认按钮并注册空子分组的音频参数字典键，修复无法新建子分组的问题（071b7ef）；菜单随之精简，隐藏针对配置项/子分组的无效操作项（bf0d379）
- **空子分组菜单精简【新增】**：空子分组三点菜单隐藏项相关操作（删除启用/未启用配置、移动启用配置、排序、导出），仅保留结构类操作；空子分组长按不再弹空菜单（722c536）
- **空子分组不显示修复【新增】**：子分组树缓存签名纳入 `subGroupAudioParamsJson`，修复新建空子分组时因签名不变导致树不重建、空子分组被隐藏（ee94cd1）
- **「编辑分组」更名「从其他分组移入配置」**：明确与长按移出的进出关系（66722a5、aa31dd0、1ec16a7）
- **一级分组菜单形态**：主菜单与长按扩展菜单曾改为 ModalBottomSheet 从底部弹出（073ad83、91cb1cb）；本轮撤销，恢复 DropdownMenu 弹窗（573f84d，见「二」）
- **标签快捷整理图标**：一级分组组名后新增快捷图标，点击直接整理全部子分组标签（58a26d8）；子分组名后同样新增，一键整理本子分组标签（016d8fa）；两者均带非空门控，分组无配置项时不显示，且与整理标签菜单项统一门控（0de2b65、2338c8d）
- **整理入口门控**：系统 TTS 列表三点菜单的「整理全部子分组标签」仅在至少一个子分组名含关键词时显示（c359c98），与标签快捷图标同批加入（见上一条）
- **标签重排跳过优化**：一键分配标签时已正确的项直接跳过，1600 人大分组全排好时 0 次 JS 计算、0 次写库（含后续编译修复 c1bea68）
- **真实计数提示**：重排完成提示实际修改数，全部已排好时提示「无需整理」，不再虚报总数
- **快捷整理图标优化【新增】**：移至行尾操作区并升级为标准 IconButton，增大尺寸与触控区（12edfb6）
- **快捷整理二次确认【新增】**：快捷整理按钮加二次确认弹窗，防止误触批量重编号标签（a4aa934）；确认弹窗提示词精简（6122f42）
- **简化多选删除流程【新增】**：去掉重复选分组弹窗和二次 armed 确认，改为一步确认即删除——选中分组 → 点删除 → 弹「确定删除 N 个分组？」→ 确认（5d07093）
