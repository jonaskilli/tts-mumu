# AI 工作记忆（跨机器迁移包）

这是目目与 WorkBuddy AI 在本项目（tts-mumu）协作时的工作记忆快照，让新电脑上的 AI 能无缝接续。

## 恢复方法（新机器）

1. 装 WorkBuddy 并登录，clone 本仓库。
2. 把本目录所有 `.md` 复制到新工作区的记忆目录：
   `<新工作区>/.workbuddy/memory/`（MEMORY.md 同名覆盖，日志按日期保留）。
3. AI 开新会话时会自动加载 `MEMORY.md`（长期要点/铁律/已否决清单），
   需要前情时按日期读 `2026-09-*.md` 工作日志。
4. git 登录：`gh auth login`；打包流程照旧（推 tag `1.26.*` 触发 Build Release）。

## 文件说明

- `MEMORY.md` — 长期工作记忆（硬约束、定案、已否决提案、当前主线）。**AI 必读。**
- `2026-09-*.md` — 每日工作日志（只追加不改写），细节溯源用。

## 更新约定

- 记忆有两处副本：本仓库（便携）+ 各机器工作区 `.workbuddy/memory/`（运行时）。
  收尾定稿时两边同步；**以本仓库为基准副本**。
- 技术文档同理：仓库 `技术文档/` 为便携副本，更新时与工作区 `E:\TTS\技术文档` 同步。

## 隐私说明

仓库公开：本目录含使用习惯与内部裁定，**无密码、无密钥、无 token**（记忆规则本就禁止存密钥）。
