# 响度均衡 — 用户说明

## 这是什么？

响度均衡是一个自动音量平衡功能。它会自动学习每个发音人的音量特征，然后把所有发音人的音量拉平，让你不用再手动逐个调音量。

## 我需要做什么？

**什么都不用做。** 功能默认开启，自动运行。

## 它怎么工作的？

1. 你播放 TTS 时，系统在后台分析这段音频的实际响度
2. 按发音人记录下来（比如"火山引擎·浑圆"这个发音人平均响度是多少）
3. 播放下一段时，自动计算增益：偏轻的发音人放大，偏响的发音人降低
4. 播得越多，学得越准

## 和手动音量调节冲突吗？

不冲突。你之前手动调的音量照常生效，响度均衡在手动调节的基础上**额外微调**。

```
你的手动音量（如 0.85x）
        ×
响度均衡自动补偿（如 1.1x）
        =
最终播放音量（0.935x）
```

## 新加了一个发音人怎么办？

直接用就行。新发音人第一段播放时增益为 1.0（不调），系统同时开始学习。播几段后就自动修正到位了。

## 换了一批发音人，旧数据没用了？

在系统 TTS 界面右上角菜单里点 **"重置响度学习数据"**，清空所有记录重新学。按钮旁边会显示已学习的发音人数量。

## 常见问题

**Q: 为什么刚开启时感觉效果不明显？**
A: 系统需要播放几段音频才能学到发音人的响度特征。学习次数越多，补偿越精准。最多学习 32 段/发音人。

**Q: 某个发音人实在太轻怎么办？**
A: 响度均衡最多放大到 loudnessMaxGain 配置值（默认 1.35 倍）。如果还不够，手动给这个发音人调一点基础音量，响度均衡会在基础上继续补偿。

**Q: 它是按什么区分发音人的？**
A: 按底层 voice（TTS 引擎的真实发音人标识）区分，不是按标签 tag。同一个 tag（如"女青年01"）下如果有多个不同 voice 的配置项，每个 voice 会各自学习、各自补偿——因为不同的 voice 确实响度不同。删除重加配置项后，只要底层 voice 相同，学习数据仍然有效。

**Q: 会不会把背景噪声也放大？**
A: 不会。系统有语音活动检测（Voice Gate），只分析有人声的部分。同时有软限幅保护，不会爆音。

**Q: 想自己看学习数据怎么办？**
A: 学习数据就保存在手机存储的 `Download/chajian/loudness_stats.json`，用任意文件管理器打开即可查看。文件长这样：

```json
{
  "晓晓 (zh-CN-XiaoxiaoNeural)": {
    "发音人": "晓晓",
    "学习次数": 12,
    "平均响度": "-22.7 dB",
    "峰值音量": "68%",
    "语音占比": "62%",
    "最后更新": "2026-08-09 15:30:00"
  }
}
```

每个发音人一条记录，字段都是中文：发音人名、学习次数、平均响度、峰值音量、语音占比、最后更新时间。每次播放新学一段后会自动更新这个文件；点"重置响度学习数据"后文件会被删除。`_内部key` 那行是程序用的，你可以忽略。

**Q: 删掉的发音人数据还在文件里怎么办？**
A: 这是正常的——响度均衡按底层 voice 记忆，删除配置项后只要底层 voice 相同，重新添加时学习数据仍有效，不用从头学。所以文件里会保留已删除发音人的记录（带发音人名方便你认出是谁）。如果你确认这批发音人都不再用了，点"重置响度学习数据"清空全部重新学即可。
