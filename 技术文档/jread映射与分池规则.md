# JRead → mumu 映射与分池规则（总结）

> 2026-08-30 定版。核心实现：`lib-database/.../entities/systts/JReadConfigMigration.kt`（映射）+ `ListManagerScreen.kt`（分池与一键整理）。
> 标签源头是「多角色朗读」朗读规则（mingwuyan）的 `tags` 表；映射、分池、一键整理全部对齐该表。

## 一、两个概念别混

| 概念 | 是什么 | 例 |
|---|---|---|
| **tag** | 内部键，规则 JS 匹配用 | `narration`、`女青年01`、`括号2` |
| **tagName** | 软件显示名，列表右上角展示 | `旁白`、`女青年01`、`在线音效` |

jread 导入时两者**一并写入**（`parse()` 经 `tagNameFor()` 查规则 tags 表取显示名）。

## 二、标签映射（mapGenericTag）

jread 的 `voiceTag` → mumu 标签，按顺序尝试以下分支，均不命中则原样保留：

| 分支 | 输入 → 输出 | 说明 |
|---|---|---|
| 旁白 | `旁白` / `narration`（忽略大小写）→ `narration` | |
| 括号显示名 | `【】括号发音人`→`括号1`、`在线音效`→`括号2`、`「」括号发音人`→`括号3`、`『对话旁白』`/`『』括号发音人`→`括号4` | 与规则 SPECIAL_ROLES/tags 表一致 |
| 主角式 | `主角 女主01`→`女主01`、`主角男主1`→`男主1` | |
| 斜杠短式 | `女/女青年3`→`女青年03`、`男/特殊5`→`特殊男05`、`女/特殊1`→`特殊女01` | |
| 长名特殊式 | `女性青年/特殊10`→`特殊女10` | 剪映官方导出形态；性别取长名主体 |
| 长名通用式 | `女性青年/通用01`→`女青年01`、`男/男性青年/通用05`→`男青年05` | 可带可选性别前缀 |
| 直写式 | `女青年5`→`女青年05`、`女青年16` 原样、`女青年007`→`女青年07`、`特殊男3`→`特殊男03` | 见下方补零规则 |

**补零规则（与朗读规则生成逻辑一致）**：
- 仅序号 **1–9** 补成 01–09；**10 及以上（含三位数 100/517/509）原样**；
- **男主始终不补零**（男主1…男主20）；
- 特殊男/特殊女按规则补零（特殊男01…20）。

**转换不了的（原样保留，导入后归高级池）**：性格词（`女性青年/甜美01`）、群杂式（`群杂/男童01`，刻意不转防撞正式角色号）、`remoteSoundN`（规则无远程音效）、`默认对话`/`默认心理活动`。

## 三、分组名映射（mapGroupName）

仅转换能对上标准人群名的形态，其余（群杂、旁白风味名、音效）原样保留：

- 剥后缀：`女性青年通用` → `女性青年` → 转短名
- 长名转短名：`女性儿童`→`女童`、`男性少年`→`少年` …（十组）
- 主角式：`主角 女主` → `女主`
- 斜杠式：`男/特殊`→`特殊男`、`女/特殊`→`特殊女`
- 紧贴复合式：`女特殊`→`特殊女`、`男特殊`→`特殊男`（剪映子分组形态）

## 四、固定标签显示名（tagNameFor）

| tag | tagName |
|---|---|
| narration | 旁白 |
| duihua / duihuaA / duihuaB | 对话 / 男 / 女 |
| 括号1~4 | 【】括号发音人 / 在线音效 / 「」括号发音人 / 『』括号发音人 |
| localSoundN | 本地音效N |
| 人群标签（女青年01 等） | 与 tag 同名 |
| 规则外标签 | 原样 |

## 五、分池规则（列表页 通用池/高级池）

**只看配置项的朗读标签（speechRule.tag），不看分组名/子分组路径/参数字典键：**

- 组内全部配置项标签满足其一 → **通用池**：
  1. 在朗读规则 tags 表内的固定标签（narration、duihua 系、括号1~4）；
  2. 人群前缀+1~3位序号（含特殊男/特殊女；序号任意，规则运行时动态扩容）；
  3. localSoundN；
  4. 能被 `mapGenericTag` 转换成上述形态的 jread 标签式；
  5. **空白标签**（未打标签不降池）。
- 任一配置项标签为规则外（性格词、群杂式、remoteSound 等）→ **整组高级池**。

数量无上限：规则初始只有 女青年01~100 也能编到 201/517（规则运行时扩容兜底 + app 侧 `expandSpeechRuleTagsIfNeeded` 补齐标签列表）；唯一隐性上限是三位数（分池正则 `\d{1,3}`，单组过千不现实）。

## 六、一键整理标签（8-30 晚定版）

- 触发：子分组名含关键词（15 个人群词 + 旁白）→ 右侧菜单「一键整理标签」；一级分组菜单另有「整理全部子分组标签」。**两级分组行内魔棒快捷键均已删**（单击立即整理无确认/少确认，易误触）；**「女性少年/男性少年」长名分组明确排除**，不因含「少年」而触发（用户指定仅「少年」名可触发）；
- 编号：组内按当前顺序 `前缀 + 01..N`（男主/特殊男女不补零）；**旁白不带序号**统一 `narration`/`旁白`；
- **防误转保护**（替代已回退的「只整理合法标签」）：旁白整理只统一旁白族（旁白X/narration）与空白标签的项，人物标签（如 jread 的 女青年01）即使在旁白命名的分组里也不改；
- **不做从组内现有标签反推前缀**（组内可能多前缀混用）；
- 已正确的项跳过（0 次 JS、0 写库）。

## 七、规则绑定（tagRuleId）

- jread 导入时自动绑定**当前启用的朗读规则**（无标签的项不绑）；
- 旧数据（未绑定的）在下一次任意导入触发的 `migrateTagNamesIfNeed(force)` 中自动回填，并顺势用规则 JS 重算显示名；
- 未绑定的配置项在编辑页点标签会提示「该配置项未绑定朗读规则，无法切换标签」。

## 八、编辑页标签选择

点标签字段 → 两层弹窗（`TagPickerDialog`，与列表页标签切换同一构件）：第一层选大分类（带项数），第二层选具体序号；单项分类（旁白/括号/音效）点分类即选中。打开前自动做标签扩容。心声芯片点亮时字段显示「心声(内心独白)」。

## 附：已知边界

- 性格/群杂是**刻意不转**（历史决定：性格词无规则映射；群杂转正式标签会撞号）；
- 已导入的旧数据 tagName/tagRuleId 不回溯，重导或触发一次导入即可回填；
- 分池人群标签正则限三位序号（`\d{1,3}`），单子分组超 999 项会落高级池（理论边界）。
