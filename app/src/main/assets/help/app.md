## 系统TTS

将网络TTS接口接入安卓系统TTS，供阅读APP调用。

### 界面说明

四个核心界面均支持右上角导入/导出，也可在设置中进行全局备份恢复。

#### 主界面
管理TTS配置列表，支持分组功能一键切换多个配置。

**快捷操作**
- 长按编辑按钮 → 试听
- 长按试听按钮 → 编辑
- 可在设置中调换按钮位置

**新增功能**
- 首页新增「重启服务」按钮，一键重启TTS服务解决异常
- 分组菜单文本简化，操作更便捷

#### 朗读规则
根据文本标签匹配TTS配置（如：旁白/对话）。

内置 `旁白对话` 规则（基于中文双引号），可直接使用。

**新增功能**
- 新增朗读规则日志调试选项，方便排查规则匹配问题

#### 插件
使用JS脚本扩展TTS功能，调用互联网TTS接口。

**新增功能**
- 插件级音频参数：每个插件可独立设置语速、音量、音高
- 音频参数默认值改为1.0，直接生效无需额外配置
- 插件管理界面使用简洁标签，避免显示异常
- 新增插件日志调试选项，支持搜索和筛选

#### 替换规则
替换朗读文本纠正发音，如：将"你好"替换为"您好"。

**高级示例**：将5字以内对话的双引号替换为【】，实现旁白朗读效果
```
启用正则表达式
替换规则：(")(.{1,5})(")
替换为：【$2】
```

## TTS转发器

将系统TTS转为HTTP网络接口，供网页或其他APP调用。

### 核心优势
- **预缓存音频**：配合阅读APP网络TTS引擎，可缓存整章音频，彻底解决段落间隔问题
- **突破限制**：通过HTTP接口调用，不受系统TTS技术限制

### 新增功能
- 转发器重启状态保存优化，重启后能正确恢复运行状态
- 保活功能合并到转发器通知，转发器运行时自动合并显示

## 后台保活

Android系统会自动清理后台应用节省电量，开启保活可确保TTS Server稳定运行。

### 推荐配置

| 用户类型 | 推荐方案 |
|---------|---------|
| 轻度使用 | 电池优化白名单 |
| 日常使用 | 白名单 + 后台保活服务 |
| 重度使用 | 白名单 + 服务 + 多种高级方案 |

### 保活方案说明

| 方案 | 特点 | 适用场景 |
|-----|------|---------|
| **电池优化白名单** | 系统功能，允许绕过电池优化 | 必开，基础设置 |
| **后台保活服务** | 前台服务+唤醒锁 | 推荐开启，兼顾省电与稳定 |
| **开机自启动** | 设备重启后自动启动 | 长期运行建议开启 |
| **无障碍保活** | 系统优先级最高，最稳定 | 极致保活 |
| **通知监听保活** | 利用通知服务保活 | 需手动开启权限 |
| **网络连接保活** | 保持网络活跃 | 对转发器特别有用 |
| **像素保活** | 1像素悬浮窗，熄屏显示亮屏隐藏 | 零打扰 |
| **定时唤醒保活** | 每分钟唤醒一次 | 耗电较高 |

**设置路径**：`设置 → 后台保活`

**重要提示**
- 本APP作为TTS引擎被调用，保活不抢占音频焦点，不影响其他APP播放
- 开启转发器时，保活通知会自动合并到转发器通知中
- 部分厂商（小米/华为等）需额外设置「厂商后台设置」

## 常见问题

### 1. 锁屏后朗读突然停止？

**原因**：Android电池优化或厂商后台限制。

**解决方法**：
1. 开启「电池优化白名单」（设置 → 后台保活）
2. 国内系统需额外允许后台运行、后台任务上锁
3. 如需长期稳定，开启多种保活方案

### 2. 段落间隔时间长？

**原因**：网络延迟，系统TTS无法预缓存音频。

**解决方法**：
- 使用TTS转发器 + 阅读APP网络TTS引擎，实现整章预缓存

### 3. 插件音频参数不生效？

**解决方法**：
- 确保插件已更新到支持音频参数的版本
- 检查插件管理界面的音频参数设置
- 使用首页「重启服务」按钮强制重启TTS服务

### 4. 转发器重启后状态丢失？

**已修复**：最新版本已优化转发器状态保存逻辑，重启后能正确恢复。
