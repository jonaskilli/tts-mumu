## 主界面

底部导航第一页，管理系统 TTS 配置列表。每个配置项 = 一个网络 TTS 接口（通过插件）或一个内置引擎。

- 支持**分组**管理，一键整组启停；配合「朗读与播放」设置中的多选开关，可同时启用多个配置/多个分组
- 列表支持拖动排序、长按多选批量操作
- 右下角 ➕ 新增配置；配置项编辑页可设置插件、发音人、音频参数（语速/音量/音高）、标签等
- 长按/点按交互细节见各页面内提示

## 角色管理

底部导航第三页（「角色」）。为朗读规则里的角色（旁白、男主、女主等）分配发音人。

- 顶栏三个入口：**书籍**（切换当前书）、**密钥**（进密钥管理）、**备份**（角色数据备份恢复）
- 按「类别」（男主/女主/旁白…）给角色挑发音人；单角色可临时换声
- 删除配置项后，相关角色会**立即随机分配替代发音人**，不留空
- 标签框末尾 🔄 一键随机重分；⋮ 菜单内有更多操作（编辑、置顶、随机分配等）

## 日志页

底部导航第二页，查看系统 TTS 朗读日志。

- 支持多选复制、按类型筛选、搜索
- 朗读规则报错会以红字显示，方便定位规则问题
- 双击标题栏空白区回到顶部

## 设置页

底部导航第四页，共 7 个分区：

| 分区 | 内容 |
|-----|------|
| **常用** | 主题、语言、备份与恢复 |
| **资源管理** | 朗读规则、插件、替换规则、密钥管理四个入口 |
| **朗读与播放** | 响度均衡、静音跳过、分段停顿、流式播放、试听/编辑按钮互换、发音人/分组多选开关 |
| **稳定性** | 最大重试、失败追加提示文本、重试上限处理、请求超时、超时看门狗 |
| **心声与标签** | 心声 AI 判定开关、标签/名称长度限制 |
| **服务与网络** | 后台保活入口、TTS 转发器（开关+运行状态）、监听端口、一键导入阅读、直链上传设置 |
| **数据与关于** | 最近任务排除、关于、帮助文档、清除网页数据、清空数据 |

页面顶部支持搜索设置项。

## 密钥管理

管理网络 TTS 接口的密钥（模型接口）。入口：设置 → 资源管理 → 密钥管理，或角色管理页顶栏「密钥」。

- 按**分组**组织，一个分组 = 一个站点/一套模型
- **启用池**：一个分组可同时启用多把密钥，朗读时按顺序自动轮换；启用池页支持长按拖动排序、单条测试、复制、编辑、移出、「测试全部」
- 密钥测试结果三态：✅ 通过 / ⚠ 能用但有代价（如思考模式未关，已自动适配）/ ❌ 不能用
- **思考模式适配**：每个模型可独立设置思考参数；默认「自动」会逐种写法试探并锁定，同站点其它模型直接继承已锁写法
- 搭配「M 直连」朗读规则使用：密钥失效时自动换池里下一把

## 备份与恢复

入口：设置 → 常用 → 备份与恢复。

- 支持**完整备份**（含敏感信息：密钥等）与**个人备份**（不含密钥）两种口径
- 备份可存本地文件夹（记住上次位置）或上传 WebDAV
- 恢复支持：从文件（zip）、从 WebDAV、从数字/直链
- 密钥可单独**覆盖导出**（自包含接口信息），导入即用
- 朗读规则/插件支持 JS 文件直导，不必先转 JSON

## TTS 转发器

把系统 TTS 转成 HTTP 接口，供阅读等 App 以「网络导入」方式调用。

- 入口：设置 → 服务与网络 → 转发器（开关即启停），端口同区可改
- **核心优势**：配合阅读 App 的网络 TTS 引擎可**预缓存整章音频**，彻底消除段落间隔
- 「一键导入」把本 App 引擎自动配置进阅读（需转发器已启动）
- 直链上传：跨设备使用时，音频可先上传网床再以链接交付（同机使用无需理会）

## 后台保活

入口：设置 → 服务与网络 → 后台保活。

Android 会清理后台应用，保活确保朗读不中断。

| 方案 | 说明 |
|-----|------|
| 电池优化白名单 | 必开的基础项 |
| 前台服务与通知 | 常驻通知保进程 |
| 唤醒锁 | 熄屏不眠 |
| 开机自启动 | 重启后自动恢复 |
| 无障碍/通知监听/网络/像素保活 | 进阶方案，按需叠加 |

- 厂商系统（小米/华为等）请在系统设置中额外允许后台运行
- 保活不抢占音频焦点，不影响其他 App 播放

## 常见问题

**锁屏后朗读停止？**
开电池优化白名单（设置 → 服务与网络 → 后台保活），厂商系统再允许后台运行；长期使用叠加多种保活方案。

**段落间隔长？**
用 TTS 转发器 + 阅读「网络导入」引擎，可预缓存整章。

**密钥测试失败？**
看卡片底部提示条（可展开复制详情）；地址要填到版本段为止（如 `https://xxx.com/v1`）；严格平台会自动适配思考参数。

**朗读没反应？**
先确认配置项已启用、阅读里选了本引擎；再看日志页红字；还不行用角色页/设置里的重启服务。
